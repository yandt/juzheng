# 居正 · 功能说明书

本说明书按界面页面逐一介绍居正的功能。使用步骤请见[使用说明书](USER-GUIDE.md)。

主菜单顺序：**首页 · 订阅 · 代理 · 规则 · 监控 · 连接 · 设置 · 源码**。

---

## 首页

应用的总览与控制中心。

- **内核开关**：一键启动/停止 sing-box 代理内核（TUN 透明代理)。启停经特权 helper 完成,无需重复授权。
- **链路状态**：以三圆点直观显示「内核 → helper → 网络」链路就绪情况。
- **代理模式切换**：Rule（规则)/ Global（全局)/ Direct（直连)三种模式即时切换,对应 `clash_api.default_mode` 与 `clash_mode` 分流规则。
- **当前节点**：显示并快速切换主代理组当前选中的节点,支持对单个节点做延迟测试(测试中显示「测试中…」)。
- **对外代理服务卡片**：显示局域网共享(公共代理)的服务状态——是否服务中、是否已鉴权,并列出其他设备可用的完整地址(本机各局域网 IP : 端口,点击复制)。未开启时提示前往设置开启。
- **流量统计卡片**：内置双序列面积图(上行/下行速率),可切换时间跨度 **1 / 5 / 10 / 30 / 60 分钟**(默认 10 分钟),并可按代理组过滤。图表支持鼠标悬停查看某时点的时间与上/下行速率。图下 6 项指标：上行速度、下行速度、活跃连接数、上行总量、下行总量、内核内存占用。

## 订阅

管理机场/自建订阅。

- **导入订阅**：粘贴订阅 URL 导入,自动拉取并解析为节点与代理组。
- **更新**：一键更新订阅内容。
- **启用/切换**：多份订阅并存,一键切换当前生效订阅。
- **重命名 / 导出 / 删除**：管理已保存的订阅。

## 代理

代理组与节点管理(对应「代理与节点」)。

- **代理组**：展示 selector（手动选择)与 urltest（自动测速选最快)两类组。可展开查看组内成员。
- **节点选择**：在 selector 组内手动切换节点。
- **延迟测试**：对整组或单个节点做延迟测速,测试过程中在延迟位置显示旋转加载 +「测试中」。
- **节点列表**：查看所有真实节点(系统隐身节点如 `to-mitmproxy`/`direct` 不展示)。

## 规则

分流规则的图形化编辑(对应 sing-box `route.rules`)。

- **有序规则**：规则自上而下,**顺序即优先级**,命中即停。
- **匹配类型**：支持 `domain_suffix`、`domain_keyword`、`domain`、`domain_regex`、`ip_cidr`、`geosite`、`geoip`、`protocol`。
- **出口指定**：每条规则指定出口(代理组 / 节点 / 直连)。
- **系统规则保真**：MITM 解密、DNS 劫持、回环打破等系统规则原样保留,不被用户规则覆盖。
- **确定性映射**：规则页所见即配置所得,序列化为 1:1 映射,无隐式合并变形。

## 监控（流量监控)

基于 go-mitmproxy 的 HTTPS 明文抓包分析。

- **启动/停止监控**：默认监听 `:9080`。
- **CA 证书**：首次使用需信任内置 CA(应用提供一键安装/复制命令);Windows 自动经 `certutil` 导入受信任根。
- **请求列表**：实时展示经代理的请求,查看 URL、方法、状态码、请求/响应明文。
- **上游代理**：可填其他代理入口(如 `127.0.0.1:7890`),流量链式经其出网。
- **内容层监控规则**：按域名等条件筛选需解密的流量。

## 连接

实时连接监控(对应 Clash API `/connections`)。

- **连接列表**：展示当前活跃连接,含目标地址、规则链(chains)、上/下行流量。
- **进程名**：开启 `route.find_process` 后,每条连接可显示发起进程名。
- **实时刷新**：经 SSE / 轮询持续更新。

## 设置

TUN、DNS、端口、日志等常用项。

- **TUN**：开关、地址、MTU、栈(system/gVisor)、网卡名、自动路由、严格路由。
- **DNS**：多 DNS 服务器(地址 + detour 出口)、分流规则(域名 → 指定 DNS)、解析策略(prefer_ipv4/ipv6 等)、兜底服务器。
- **端口**：mixed-back 回注端口等。
- **局域网共享**：开启后对外提供混合(HTTP+SOCKS5,同端口)代理入站(绑 `0.0.0.0`,默认端口 7890),供同网段其他设备使用;可选用户名/密码鉴权。其他设备把代理设为「本机局域网 IP : 端口」即可经本机出网(默认走主代理,命中用户规则的按规则分流)。修改后需重启内核生效。
- **日志级别**：trace/debug/info/warn/error。

## 源码

- **原始配置编辑**：直接查看/编辑底层 sing-box JSON 配置。
- **双向同步**：图形编辑与源码互为映射,改一处另一处同步(解析失败时提示,可在源码模式修复)。
- **未图形化字段透传**：图形界面未覆盖的高级字段原样保留,不丢失。

---

## 系统集成

- **系统托盘**：常驻托盘,图标随内核运行状态变化(macOS 单色 Template 自适应明暗菜单栏,以形状区分运行/待机)。
- **后台常驻**：关闭窗口最小化到托盘,内核持续运行。
- **跨平台特权 helper**：macOS 经 launchd、Windows 经系统服务(SCM)运行内核;Windows 内置 `wintun.dll`,TUN 开箱即用。
